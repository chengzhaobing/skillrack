# 设计令牌：缓动、时长、材质与配色

本文件是全项目动效的唯一数值来源。做任何新效果前先在这里选参数，不要在页面里现编 ease 和 duration。
数值取自 `scaffold-vue/src/composables/motion.ts`、`src/styles/tokens.css` 与 `DESIGN.md`。

可直接引用的变量文件：`../assets/motion-tokens.css`。

## 1. 缓动：五条具名曲线，各有语义

| 名称 | 值 | 语义 | 用在哪 |
| --- | --- | --- | --- |
| `reveal` | `expo.out` | 显现 | 内容入场、级联、描边、读数落定后的收尾 |
| `glide` | `power4.out` | 滑行 | 位移类：页面推进、滑块、卡片让位、视口平移 |
| `exit` | `power2.in` | 退场 | 任何离开：遮罩淡出、页面退场、浮层收起 |
| `swap` | `power2.inOut` | 交接 | 双向形变：按钮收缩、折线变形、路径描绘 |
| `settle` | `back.out(1.6)` | 落定 | 一次轻微过冲的确认：松手回弹、Toast 弹入、对勾、柱子 |

规则：

- 进入用 `out` 家族（先快后慢，符合"出现要利落"）；离开用 `in`（先慢后快，符合"消失要干脆"）。
- `back.out` 只用于**状态的确认**（提交成功、落位、松手），一个屏幕同时最多两处；所有东西都弹跳等于都不弹跳。
- `elastic` / `bounce` 在本项目里不用：弹性靠 `back.out(1.6)` 加弹簧函数实现，保真且不廉价。
- 需要新曲线时先问：能不能用上面五条？确实要（比如品牌专属的刹车感）才上 `CustomEase`，并把它加进本表。

## 2. 时长：按"你在告知什么"分级

| 令牌 | 值 | 用在哪 |
| --- | --- | --- |
| `press` | 0.14s | 按下瞬间的压缩，必须早于视觉反馈的感知阈值 |
| `release` | 0.46s | 松手回弹（比按下长 3 倍：按下去要快，弹回来要有质感） |
| `hoverIn` | 0.34s | 悬停抬起、光斑亮起 |
| `hoverOut` | 0.42s | 离开回落（略慢于进入，避免指针扫过时抖动） |
| `slide` | 0.52s | 玻璃滑块、开关、树箭头这类"切换" |
| `pageOut` | 0.18s | 页面退场（短，让路由感觉即时） |
| `pageIn` | 0.62s | 页面进场（长，允许有编排） |
| `overlayIn` | 0.42s | 弹窗/抽屉进入 |
| `overlayOut` | 0.2s | 弹窗/抽屉离开 |

补充经验值（项目内已在用，未进 `DUR`）：

| 场景 | 值 |
| --- | --- |
| 指针跟随（`quickTo`） | 0.32–0.6s，`power3.out` |
| 滑块/形变等一次性布局动画 | 0.42–0.62s |
| 图谱开场涟漪 | 1.8s |
| 图表描绘 | 1.1s；数据间形变 0.72s |
| 列表行级联 | 每行 0.025s（最多 14 行） |
| 卡片级联 | 每张 0.045–0.05s（`from: center` 或 `start`） |
| 面板内容级联 | 每项 0.07–0.09s（最多 18 项） |
| 打字机 | 42ms/字 + 180ms 收尾停顿 |

时长与距离的关系：位移越大时长越长，但**增长要亚线性**。12px 用 0.5s，120px 用 0.72s，整屏推进用 0.62–0.9s，不要 1.5s 以上（除了叙事型滚动）。

## 3. 能量语态：每个效果都要能说出自己在做什么

这是本项目最有效的约束：说不出语态的效果就是装饰，不做。

| 语态 | 含义 | 对应效果 |
| --- | --- | --- |
| 蓄 Charge | 输入、聚焦、预备 | 悬停抬起、指针光、输入框焦点环 |
| 放 Discharge | 开始工作、释放 | 按压压缩、主按钮涟漪、弹窗从触发点展开、抽屉生长、批量浮条升起、登录按钮收拢 |
| 导 Conduct | 进行中、数据在流 | 折线描绘与形变、刻度环逐根点亮、连线脉冲、TimeLine 推进、Toast 倒计时环 |
| 结 Crystallize | 交付落定 | 读数逐位落定、柱子生长、卡片落位、对勾描边、开场涟漪结束 |
| 停摆 Halt | 停止、恢复默认 | 抽屉收回原行、拖拽取消飞回、浮条下沉、错误抖动后复原 |

写代码时把语态写进注释（`// 结 Crystallize`），比写"淡入淡出"更有用。

## 4. 圆角、阴影、材质

### 圆角（4px 一档，5 级）

| 令牌 | 值 | 用在哪 |
| --- | --- | --- |
| `--r-xs` | 8px | 小控件、图标按钮、单元格 chip |
| `--r-sm` | 12px | 标准按钮、输入框、导航项、滑块 |
| `--r-md` | 16px | 浮层菜单、读数块、登录按钮 |
| `--r-lg` | 20px | 面板、查询区、卡片 |
| `--r-xl` | 24px | 主卡、弹窗、抽屉 |

例外：胶囊一律 `999px`（标签、Toast、开关、登录成功圆）。小方形控件（17px 勾选框）用 5px 才读得出"方"。

### 阴影：接触阴影 + 环境阴影两层

| 令牌 | 用途 |
| --- | --- |
| `--e1` | 阅读面（表格容器、普通卡片） |
| `--e2` | 高亮玻璃块（选中项、次级按钮） |
| `--e3` | 浮层（下拉、命令面板、弹窗、抽屉） |
| `--e-accent` | 主按钮（蓝） |
| `--e-danger` | 危险按钮（红） |
| `--edge` | 1px 内高光，让材质有"厚度" |

深色主题不要复用浅色阴影：换成 `rgba(0,0,0,.3–.42)` 的两层，否则会发灰。

### 四种材质 + 一种光

| 类 | 特征 | 用途 |
| --- | --- | --- |
| `m-rail` | 近实色 + blur(22px) | 导航轨 |
| `m-pill` | 最亮白边 + 内高光 + blur(22px) saturate(1.18) | 选中导航、滑块、次级按钮 |
| `m-float` | 最重模糊 blur(28px) + `--e3` | 下拉、命令面板、Toast |
| `m-surface` | 浅色态**关掉** backdrop-filter | 卡片、表格、弹窗（可读性优先） |
| `m-groove` | 只有内阴影 + 半透底 | 分段控件底座、导入列表（读作"凹槽"） |
| `m-glow` | 容器级指针光（`--px/--py` + 120px 径向渐变，`mix-blend-mode: screen`） | 主卡、登录卡（材质，不是可点承诺） |

规则：玻璃只用于**层级**，不铺满页面；表格与正文所在的面必须是 `m-surface`。`prefers-reduced-transparency: reduce` 时全部退化为实色。

## 5. 配色

| 语义 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| 主操作 | `#236de9` | `#4c8dff` | 选择、主按钮、激活图标 |
| 正常 | `#82dd2d`（文字 `#58a021`） | `#9be35a` | 成功、在线、能力 |
| 警示 | `#ff5a50`（文字 `#e0443b`） | `#ff7a71` | 危险、失败 |

分类色 5 组（沙/天/丁香/玫瑰/薄荷）**只区分类别**，不表示状态：看板列、泳道、占比条、组织分支、图谱节点。状态必须同时有文字或图标。

字色五档：`--ink` / `--ink-muted` / `--ink-soft` / `--ink-faint` / `--leaf-text`。动效里做"退暗"时用透明度（0.25–0.45）而不是换灰色，避免主题切换时对不上。

## 6. 排版与密度

- 字体：系统栈（SF Pro / 苹方 / Noto Sans SC / 微软雅黑），不联网加载。
- 等宽只给数字、编码、权限标识与时间。
- 读数：`--fs-display-xl` 56 / `-l` 40 / `-m` 28，配 `tnum`。
- 控件高度：`--control-h` 36px，`--control-h-sm` 30px；表格行高 48 / 56 / 40（标准 / 宽松 / 紧凑）。
- 间距节奏：4 / 8 / 12 / 16 / 20 / 24。卡片内距 20–22px，区块间距 16px。

## 7. 层级（z-index）

`--layer-overlay: 200`、`--layer-toast: 400`，浮层内部菜单 120，导航 110。动效里做"退远"用 `scale 0.98` + `opacity` 降亮，不要改 z-index 来做层次。

## 8. reduced-motion 的统一降级

```css
@media (prefers-reduced-motion: reduce) {
  /* 只保留状态层：透明度瞬切，位移与缩放取消 */
  .btn, .nav-item, .checkbox-box, .switch-knob, .tree-toggle svg { transition-duration: 1ms !important; }
  .m-glow > .glow-layer { display: none; }
}
```

```js
const mm = gsap.matchMedia();
mm.add('(prefers-reduced-motion: reduce)', () => {
  // 直接给终态，不建时间轴
  return () => { /* mm.revert() 会自动清理，这里只处理脚本之外的状态 */ };
});
```

降级原则：**效果可以消失，状态不能消失**。圆环要立刻是完整的，对勾要立刻可见，Toast 要立刻出现，不能因为减少动效而卡在"进行中"的视觉上。

## 9. 反模式（这些是"通用 AI 风格"的来源）

- ❌ 每个元素都 `y: 40, opacity: 0, duration: 1, stagger: 0.2`：节奏拖沓且毫无层次。
- ❌ 全局紫蓝渐变 + 大圆角发光卡片 + 到处都是 blur 玻璃。
- ❌ 所有悬停都 `scale: 1.05` 且没有 `transform-origin` 设计（文字会糊）。
- ❌ 用 emoji 当图标或状态标记。
- ❌ 无限循环的装饰动画（呼吸、旋转、闪烁），除了真实进行中的状态指示。
- ❌ 同一屏三个以上元素各自弹跳、各自过冲。
- ❌ `transition` 和脚本抢同一个属性（`transform` / `opacity` 归脚本，颜色与阴影归 CSS）。
- ❌ 用 `delay` 把多步动画串起来（用时间轴的 position 参数）。
