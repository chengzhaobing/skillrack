快速开始

不用全局安装，npx 每次取最新版。

  1. 在项目根目录执行 npx skillcrate add motion-recipes，CLI 会打印像素字横幅与落位结果。
  2. 默认自动探测 .codebuddy / .claude / .cursor / .agents，命中哪个装哪个。
  3. 装到别的宿主：--to claude；装到全局：--global；装到自定义目录：--to ./shared/skills。
  4. 重启宿主会话，技能即被加载；不想要了就 npx skillcrate remove motion-recipes。

命令手册

全部命令零交互，退出码 0 成功 / 1 失败，可直接进 CI。

命令作用
skillcrate list列出全部技能（默认命令）
skillcrate add <skill>安装本仓库技能
skillcrate add <repo> --skill <name>从 GitHub 仓库安装
skillcrate add <path>安装本地技能目录
skillcrate info <skill>详情、体积、安装命令
skillcrate remove <skill>卸载

选项

选项说明
--skill, -s指定技能名（远程仓库必填）
--to, -tcodebuddy / claude / cursor / agents 或自定义路径
--global, -g装到用户目录，所有项目可用
--force, -f覆盖已存在的同名目录
--branch, -b指定远程分支或 tag

目录结构

技能目录名 = 技能名 = frontmatter name，三者必须一致。
